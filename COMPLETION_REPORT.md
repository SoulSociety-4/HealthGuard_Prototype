## 2. First Aid integration

Source: the supplied healthguard_redesign standalone index.html, style.css and script.js, also present in Healthguard_Frontend.zip. Data was parsed from script.js without executing it.

All 435 protocols and 20 categories were retained. Twenty-one repeated source IDs receive stable UI suffixes; original IDs and all medical text remain preserved. The source SHA-256 is recorded in DATA_IMPORT.md.

The lazy-loaded, authenticated /first-aid route uses typed data, reusable FirstAidCard and FirstAidDetail components, the existing dialog, and native React interactions. It includes search, category/severity filters, pagination, detail views, warnings, numbered source steps, cautions, emergency links, empty states and persistent saved protocol IDs. No iframe, raw HTML execution, or new runtime dependency was introduced.

Bookmarks contain only protocol identifiers in browser storage. Health records and auth data continue through the existing backend.

## 3. Logo fix

The official 2108 × 648 PNG already has a transparent alpha channel. White CSS wrapper backgrounds caused the visible rectangles. Removed those backgrounds from the affected sidebar, footer and About treatments, retaining the same artwork, colors and aspect ratio. Public assets were not modified.

## 4. Typography

Replaced inconsistent literal font sizes with rem-based semantic tokens across the application: 16px body, 14px readable data, 13px secondary labels and responsive 32–40px page headings at default browser sizing. Shared line-height and weight tokens are documented in DESIGN.md and DESIGN_SYSTEM.md. Hospital metadata and specialty controls were adjusted for readability; Academy card content remains scroll-accessible when enlarged.
